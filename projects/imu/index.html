Overview

Embedded IMU development

This project implements an embedded inertial measurement system using an STM32F303 Discovery board.

The system interfaces with accelerometer, gyroscope and magnetometer sensors and provides software for acquiring and processing the resulting measurements.

The firmware was developed in C using STM32CubeMX and the STM32 HAL, with additional Python tooling used for calibration, data collection and analysis.

Engineering

What I worked on

Sensor interfaces

Implemented low-level interfaces for the IMU sensors and handled acquisition of accelerometer, gyroscope and magnetometer data on the microcontroller.

Sensor calibration

Developed calibration workflows for the sensors and collected measurement data for determining sensor characteristics and calibration parameters.

Data processing

Built supporting Python tools for collecting, processing and visualising measurements from the embedded system.

Embedded development

Worked with STM32 peripherals, firmware configuration, build tooling and communication between the embedded target and host computer.

Workflow

From sensor to analysis

  1. 01
    Configure hardware

    Configure the STM32 peripherals and sensor interfaces using STM32CubeMX.

  2. 02
    Acquire measurements

    Read inertial sensor data from the embedded target and transfer measurements to the host system.

  3. 03
    Calibrate sensors

    Collect calibration data and determine parameters used to improve measurement quality.

  4. 04
    Analyse data

    Use Python tooling to process and visualise the collected measurements.
