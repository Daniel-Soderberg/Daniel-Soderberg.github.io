Overview

About the project

This project implements an embedded inertial measurement unit using an STM32F303 Discovery board.

The system interfaces with accelerometer, gyroscope and magnetometer sensors and provides a software interface for collecting and processing the measured data.

The project was developed using STM32CubeMX and STM32 HAL, with the application code written in C.

Technical focus

Embedded sensor processing

The project includes low-level interfaces for the IMU sensors and software for reading and processing sensor measurements on the STM32 microcontroller.

Sensor calibration and data collection are supported through additional Python scripts running on a host computer.

The project also includes magnetometer calibration data and tools for visualising the collected IMU measurements.

Project structure

Source and configuration

The STM32CubeMX project configuration is stored in the IMU.ioc file. Generated STM32 firmware packages and build artifacts are intentionally excluded from the repository.

The repository contains the application source code, sensor drivers, startup and linker files, Makefile and Python-based supporting tools.

A new checkout can be configured by opening the IMU.ioc file in STM32CubeMX, generating the required files and then building the project using the included Makefile.
