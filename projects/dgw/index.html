Platform STM32F3
Language C
RTOS FreeRTOS

Overview

Embedded data gateway

This project implements an embedded data gateway using an STM32F3 Discovery board. The system is designed to communicate with external devices using multiple communication interfaces.

A Modbus RTU interface was developed over USART, providing serial communication with external devices using the Modbus protocol.

The system also interfaces with a CAN bus through MCP2551 CAN transceivers. The firmware uses FreeRTOS to manage the different communication tasks and coordinate the gateway functionality.

Architecture

Communication architecture

The system combines multiple communication interfaces with a FreeRTOS-based firmware architecture. Communication handling is separated into dedicated software components running on the STM32 microcontroller.

Modbus RTU Serial communication protocol implemented over USART
USART STM32 serial peripheral used for Modbus communication
CAN CAN communication through the STM32 CAN peripheral
MCP2551 External CAN transceivers providing the physical CAN interface
FreeRTOS Real-time task scheduling and coordination of firmware functionality

Workflow

From MODBUS to CAN and vice versa

  1. 01
    MODBUS

    USART communication is set up with DMA and interrupts. The DMA buffer is processed when the idle line interrupt is set. The data is then sent to a FreeRTOS buffer to be processed.

  2. 02
    CAN

    A MCP2551 transceiver is connected to the board with the Rx and Tx pin. The MCU is configured with receive interrupt. When data is received it is put in a FreeRTOS buffer for processing.

  3. 03
    Data Gateway

    For gateway functionality a signal abstraction layer is utilzed. The CAN and MODBUS driver can read from or write to the signal layer depending on the setup.
