Motor Control Development

Embedded motor control development using an IHM03 motor development kit, with manually configured STM32 peripherals, synchronized PWM and ADC sampling, and open-loop Space Vector Modulation.

Platform IHM03
Language C
Control Open-loop SVM

Overview

Embedded motor control

This project focuses on developing a microcontroller-based motor control system using an IHM03 motor development kit.

The project uses STM32CubeMX to generate the initial firmware configuration, while the required peripheral setup and timing configuration have been developed with the motor-control application in mind.

The current implementation uses synchronized PWM generation and ADC sampling together with open-loop Space Vector Modulation to control the motor.

Engineering

What I worked on

Peripheral configuration

Configured the STM32 peripherals required for the motor-control application, including timer and ADC functionality.

Center-aligned PWM

Configured PWM generation using up-down counting mode to create center-aligned switching suitable for the motor-control application.

ADC synchronization

Configured ADC sampling around the PWM switching cycle so that current measurements are taken during suitable off-cycle intervals for the low-side current measurement.

Space Vector Modulation

Implemented open-loop Space Vector Modulation to generate the three-phase PWM duty cycles used to drive the motor.

Architecture

PWM and current measurement

The control system is built around the timing relationship between PWM generation and ADC sampling. The PWM timer operates in up-down counting mode, while ADC measurements are synchronized with the switching cycle.

Because the development kit uses low-side current measurement, the ADC sampling window is placed during suitable PWM off cycles to obtain the current measurements.

PWM Timer Center-aligned PWM using up-down counting mode
ADC Current measurement synchronized with the PWM switching cycle
Low-side sensing Current measurements taken during suitable PWM off cycles
SVM Space Vector Modulation generating three-phase PWM duty cycles
STM32CubeMX Microcontroller peripheral configuration and initialization

Control workflow

From reference to motor drive

  1. 01
    Configure peripherals

    Configure the STM32 timers, ADC and supporting peripherals for the motor-control application.

  2. 02
    Generate voltage reference

    Generate the rotating voltage reference used by the open-loop motor-control system.

  3. 03
    Apply Space Vector Modulation

    Convert the voltage reference into three-phase PWM duty cycles for the motor inverter.

  4. 04
    Sample motor currents

    Trigger ADC measurements during suitable PWM off cycles to acquire current information from the low-side measurement circuitry.

Current status

Open-loop control

The current implementation focuses on establishing the low-level motor-control infrastructure and validating PWM timing, ADC sampling and Space Vector Modulation.

The system currently operates in open loop, providing a foundation for further development of current measurement processing and closed-loop motor-control functionality.
