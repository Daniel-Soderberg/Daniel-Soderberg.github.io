Motor Control Development

Embedded motor control development using an IHM03 motor development kit, with manually configured STM32 peripherals, synchronized PWM and ADC sampling, and open-loop Space Vector Modulation.

Platform IHM03
Control Space Vector Modulation
Development STM32CubeMX · C

Overview

Embedded motor control

This project focuses on developing a microcontroller-based motor control system using an IHM03 motor development kit.

The project started with configuring the microcontroller peripherals using STM32CubeMX. The peripheral configuration and timing requirements were then developed with a focus on the requirements of motor control.

The current implementation uses synchronized PWM generation and ADC sampling together with open-loop Space Vector Modulation to control the motor.

Engineering

What I worked on

Peripheral configuration

Configured the required microcontroller peripherals using STM32CubeMX, with the peripheral setup selected specifically for the motor-control application.

PWM generation

Configured the PWM timer for center-aligned operation using up-down counting mode, providing symmetrical switching suitable for motor-control applications.

Synchronized ADC sampling

Configured ADC sampling to occur during the PWM off cycles. This is particularly important for the low-side current measurement topology used by the motor development kit.

Space Vector Modulation

Implemented open-loop Space Vector Modulation to generate the three-phase PWM signals required to drive the motor.

Architecture

PWM and current measurement

The control system is built around the timing relationship between PWM generation and ADC sampling. The PWM timer operates in up-down counting mode, while ADC measurements are scheduled during the switching intervals where the low-side current measurement provides a suitable measurement window.

PWM Timer Center-aligned PWM using up-down counting mode
ADC Current measurement synchronized with the PWM switching cycle
Low-side sensing Current measurements taken during appropriate PWM off cycles
SVM Space Vector Modulation generating three-phase voltage references
STM32CubeMX Peripheral configuration and microcontroller initialization

Control workflow

From voltage reference to motor drive

  1. 01
    Configure peripherals

    Configure the STM32 timers, ADC and supporting peripherals for the motor-control application.

  2. 02
    Generate voltage references

    Calculate the desired rotating voltage vector for the open-loop motor-control system.

  3. 03
    Apply Space Vector Modulation

    Convert the voltage reference into the corresponding three-phase PWM duty cycles.

  4. 04
    Sample motor currents

    Trigger ADC measurements during suitable PWM off cycles to acquire current information from the low-side measurement circuitry.

Current status

Open-loop control

The current implementation focuses on establishing the low-level motor-control infrastructure and validating the PWM, ADC timing and Space Vector Modulation functionality.

The system currently operates in open loop, providing a foundation for further development of current measurement processing and closed-loop motor-control functionality.
